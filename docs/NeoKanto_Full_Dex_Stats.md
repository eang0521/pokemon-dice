# Neo Kanto Full Dex Stats

*Die-face conversion for all 199 Pokémon in the regional dex. Each of the six base stats (HP/Atk/Def/SpA/SpD/Spe) is divided by 17.5 and rounded to the nearest integer. Zero is a legal result — a very low stat producing a literal 0-face is thematically appropriate for a few outlier Pokémon and doesn't break anything.*

## Notes

- **Only one species rolls a literal 0-face: Chansey**, on both its Attack and Defense dice (base 5 each — the famously fragile offense/defense that comes with its huge HP/SpD). Nothing else in the dex, not even Magikarp, drops all the way to zero on any stat.
- `NeoKanto_Gym_Pokemon_Stats.md` is a strict subset of this doc — die values for any species appearing in both are identical, since it's the same conversion applied to the same source stats.
- Habitat groupings match `NeoKanto_Regional_Dex.md` exactly, so the two docs can be cross-referenced directly.
