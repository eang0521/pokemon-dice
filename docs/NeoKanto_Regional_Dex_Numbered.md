# Neo Kanto Regional Dex — #1–199

*Canonical numbered dex. Every other Neo Kanto doc keys off these numbers and species names. Grouped by habitat zone (the town each zone's routes/dungeons feed into), following the finalized map in the Neo Kanto Dossier §7.*

*No baby/pre-evolution Pokémon are included (Pichu, Igglybuff, Cleffa, Mime Jr., Elekid, Munchlax, Happiny, Tyrogue, and Smoochum's baby role, plus Magby) — removed per request, along with Hitmontop, whose only path into the dex was through the now-removed Tyrogue.*
