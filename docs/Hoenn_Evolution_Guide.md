# Hoenn Region — Evolution Guide

Hoenn uses the same **1-20 level scale** as Calli and Neo Kanto (ruleset §10). Every level shown below is already converted to that scale — no raw mainline levels appear anywhere in this doc.

Non-level evolutions (stone, trade, friendship) get a "proper level" via the buffer rule (ruleset §11) for internal trainer-roster bookkeeping only — it is not a level requirement the player ever needs to hit. None of Hoenn's non-level splits have a level-based sibling in the same split (Gloom's two branches are both stone-based, Clamperl's two branches are both trade-based), so the buffer rule's sibling-borrowing exception is never exercised in this dex, and no entry below needs a level annotation on its item/trade method.

**This dex is the real, official Pokémon Emerald Hoenn Regional Dex, minus Jirachi, Deoxys, Regirock, Regice, Registeel, and the three baby Pokémon Azurill, Igglybuff, and Pichu (194 species) — nothing was added to it.** The babies were cut by request — their evolved lines (Marill, Jigglypuff, Pikachu) stay in and are simply treated as base species now. See `Hoenn_Dungeons.md` for why each was cut. A handful of evolutions that exist in later generations (Nosepass→Probopass, Girafarig→Farigiraf, Magneton→Magnezone, Kirlia→Gallade, Snorunt→Froslass, Dusclops→Dusknoir, Rhydon→Rhyperior, Roselia→Roserade) target species introduced after Generation III and were never added to Emerald's fixed regional dex — those lines simply stop one stage earlier here, matching the source game.

Towns are ordered by when you would first pass through them; each evolution is filed under the town where its pre-evolution (or its own species, for base Pokémon) is first available — matching the convention used in `Calli_Evolution_Guide.md` and `NeoKanto_Evolution_Guide.md`.

## Species with no evolution in this dex

Everything else in the 194-species list is either genuinely single-stage in the source games (Nosepass, Girafarig, Absol, Sableye, Torkoal, Tropius, Skarmory, Relicanth, Corsola, Luvdisc, Lunatone, Solrock, Chimecho, Wobbuffet, Heracross, Pinsir, Castform, Kecleon, Spinda, Mawile, Volbeat, Illumise, Plusle, Minun, Delcatty [as the final stage], every Legendary/Mythical) or a final evolutionary stage already reached in the table above. Roselia has no in-dex evolution (Roserade is a Gen 4 addition) and stays single-stage here despite technically having a canon pre-evolution (Budew) and evolution outside this dex's scope.

## Notes

- **Trade evolutions** work the same as Calli's and Neo Kanto's precedent — an in-game trade-kiosk NPC stands in for a second physical copy.
- **Friendship evolutions** (Golbat) trigger the first time the Pokémon levels up to at least 4 levels above the level it was obtained at — this game tracks no hidden friendship stat, so that's the concrete, player-trackable stand-in (ruleset §11).
- **Wurmple's split** (Silcoon/Cascoon, and consequently Beautifly/Dustox) is randomized by an internal personality value in the source game, not a player choice — this project rolls it randomly the same way, same convention as any other branching evolution (ruleset §11).
- **Item evolutions never trigger automatically on level-up** — Water Stone, Leaf Stone, Sun Stone, Moon Stone, Fire Stone, Thunder Stone, Trade, and Friendship (catch Lv +4, the one exception that IS automatic) all work exactly like Calli's dex: the Pokémon only evolves when the player uses the matching option at a town that has the item (or, for Friendship, on its own automatic threshold). No item-based evolution in this dex has an inherent level requirement.
