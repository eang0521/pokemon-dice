# Calli Region — Gym Leader Pokémon: Die Stats

Each Pokémon's six die faces are its normal base stats — HP, Attack, Defense, Sp. Atk, Sp. Def, Speed, in that order — each divided by 17.5 and rounded to the nearest whole number. Calli doesn't track them as named stats; they're just the six sides of the die that Pokémon rolls in battle. The order below is kept consistent for reference, but nothing stops a table from being read as six unlabeled numbers.
