# Neo Kanto Trainer Classes

*First pass. All 11 classes are terrain-neutral by design — none of them require specific terrain to make sense as a concept, so any of them can plausibly turn up on any route or dungeon in the region. Legendaries/Mythicals are deliberately excluded from every table below; they stay reserved for their signature locations (see `NeoKanto_Regional_Dex.md`). Every table lists each line's **base (unevolved) species** — the trainer's actual level (see Team Size & Level below) determines which stage of that line you actually fight, resolved against `NeoKanto_Evolution_Guide.md`.*

## The 11 Trainer Classes

| Roll | Class | Flavor |
|---|---|---|
| 2 | Ace Trainer | Rare, elite battler — a genuinely strong, varied team |
| 3 | Veteran | Experienced, tough-minded, Fighting-leaning |
| 4 | Bird Keeper | Flying-focused hobbyist |
| 5 | Bug Catcher | Bug-focused hobbyist |
| 6 | Cyclist | Fast-moving, Electric-leaning |
| 7 | Youngster | Everyday kid — the most common trainer in the region |
| 8 | Lass | Everyday, friendly, varied |
| 9 | Hiker | Mountain/route generalist, Rock/Ground-leaning |
| 10 | Camper | Outdoorsy generalist, Grass/Bug-leaning |
| 11 | Backpacker | Rugged wanderer, cave/route generalist |
| 12 | Silph Researcher | Rare, tech-and-Psychic-leaning fieldworker |

*The most generic class (Youngster) sits at 7, the most probable roll. The two rarest/most unusual classes (Ace Trainer, Silph Researcher) sit at the 2/12 extremes — flavor matches actual frequency, not the reverse.*

## Team Size & Level

| Badges | Team size | Pokémon level |
|---|---|---|
| 0 | 1 | base + 0 |
| 1–2 | 2 | base + badges |
| 3–4 | 3 | base + badges |
| 5–6 | 4 | base + badges |
| 7–8 | 5 | base + badges |

*Team size is tiered; level is a flat formula using the exact badge count, not the tier — level increases every badge, even within a team-size bracket.*

## Notes

- Every table lists 11 genuinely distinct lines — no line (by base species) repeats within a single class's own table. The same line can and does recur **across** different classes (e.g., Deino's line anchors Ace Trainer, Veteran, Bug Catcher, and Silph Researcher) — that's intentional; reuse across classes is expected, only within-class repeats are disallowed.
- Table cells show the **base species only**. A low-badge encounter with, say, Machop (Veteran, slot 2) stays a Machop; a high-badge encounter with the same slot resolves to Machoke or Machamp per the evolution guide's level thresholds. This is what makes the same 11-slot table stay relevant across the whole badge range instead of needing separate early-game/late-game tables.
