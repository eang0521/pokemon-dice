# Neo Kanto Gym Pokémon Stats

*Die-face conversion for every Pokémon used by the 8 gym leaders. Each of the six base stats (HP/Atk/Def/SpA/SpD/Spe) is divided by 17.5 and rounded to the nearest integer. Zero is a legal result — a very low stat producing a literal 0-face is thematically fine for a handful of outliers and doesn't break anything.*

## Notes

- No gym Pokémon rolled a literal 0-face this pass — the lowest values (Magnemite's Die 1 = 1, several Die 6/Die 4 values at 1–2) come from genuinely low base stats, not a conversion error.
- This is a strict subset of `NeoKanto_Full_Dex_Stats.md` — die values for any species appearing in both docs are identical, since they're the same conversion applied to the same source stats.
