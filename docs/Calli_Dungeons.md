## Notes

- **Fully connected network confirmed:** every town is reachable from Redwood Town, and several clusters have more than one path in — Basin Town can be reached via Capitol (Route 10→14) or via Crag (Route 13→14); Skyline City loops back toward the Basin/Mission area via Routes 22–23 as a second path, independent of the direct Mission–Skyline route (21). This redundancy supports the free gym-order design well.
